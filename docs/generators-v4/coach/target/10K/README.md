Šta šabloni 10K treba da preuzmu (razlike prema polumaratonu):
- dugi 30–33 % nedelje, bez bloka; sadržaj je završnica 10–15 min u T ili RP i progresivna poslednja 3 km;
- provera forme je trka ili test 5 km (početnik i < 25 km/ned: 3 km) u subotu rasteretne nedelje;
- lestvica T do 28 min u komadu, I 14 → 22 min kroz 3 nedelje, RP 23 → 29 min; najteža nedelja 3 nedelje pred trku
  (plan ≤ 8 nedelja: 2), sledeća ≤ 85 %;
- brz rad ≤ 22 % vremena nedelje; prvi kvalitet najranije 4 dana posle trke ili testa;
- obim po danima u ovim planovima je trenerska procena, generator ga nije proverio.
